Connect sign-in back to Relay

Credentials identify your app. Each provider also needs the exact callback address below.

01

YouTube callback

Open Google Cloud → Credentials, edit the Web application OAuth client, add this under Authorized redirect URIs and save. Enable YouTube Data API v3.

02

Instagram callback

Instagram requires public HTTPS. Point BASE_URL at an HTTPS host or tunnel, restart Relay, and open the workspace through that same address.

Then in Meta for Developers → Instagram → API setup with Instagram login → Business login settings, add this under OAuth redirect URIs.

03

Pick an account

Allow popups for this site, then hit Connect. Google asks which account to use. After consent the window closes and the list updates.

Everything must match exactly: scheme, host, port, path, trailing slash.
